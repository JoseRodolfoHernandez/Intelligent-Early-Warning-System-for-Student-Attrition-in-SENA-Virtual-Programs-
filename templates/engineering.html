Phase 3: Data Engineering Pipeline

Data Cleaning & Structural Handling

To eliminate processing bottlenecks during model execution, the pipeline implements automated cleaning layers:

  • Token Sanitization: String fields were stripped of recursive string modifiers (such as double quotation wrappers ""VIRTUAL"") using vector text utilities.
  • Temporal Conversions: Date parameters (FECHA_INICIO_FICHA and FECHA_TERMINACION_FICHA) were parsed into true standard date tokens.

Feature Preparation & Transformations

  • Categorical Encoding: Implemented One-Hot Encoding mechanisms on high-cardinality values, producing binary column expansions to support algorithmic calculations.
  • Feature Synthesis: Created the continuous independent feature DURATION_DAYS via vector date subtraction to isolate mathematical timeline variations.
  • Target Formulation: Synthesized the target continuous response parameter ATTRITION_RATE by evaluating active dropouts relative to initial group registration.
