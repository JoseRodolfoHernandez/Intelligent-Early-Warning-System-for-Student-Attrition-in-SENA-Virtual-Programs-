Phase 3: Data Engineering

Data Cleaning & Wrangling Pipeline

The automated data preparation script filters and cleans corrupt string literals, standardizing the text tokens into neat categorical arrays.

Feature Engineering & Transformations

  • Temporal Math: Date fields (FECHA_INICIO_FICHA) were converted into datetime objects to mathematically compute continuous active time values (DURATION_DAYS).
  • Categorical Encoding: Features like NOMBRE_REGIONAL and NIVEL_FORMACION are mapped through categorical processing to serve as matrix inputs for model aggregations.
  • Target Variable Synthesis: The dependent variable (Attrition Rate) was engineered by computing the ratio of dropped-out records against total initial course registration.
