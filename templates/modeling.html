Phase 4: Model Engineering

Implementation, hyperparameter tuning, and training process of three distinctive Machine Learning models to predict student attrition in SENA Virtual Programs.

Dataset Split: 80% Training (12,320 rows) | 20% Validation (3,080 rows).
Model 1: Random Forest

Ensemble method based on parallel decision trees. Designed to handle high-cardinality regionals without overfitting.

Parameters:n_estimators=200, max_depth=15
Target:Attrition Rate (Continuous)
Model 2: Gradient Boosting

Sequential boosting technique minimizing residual errors step-by-step through gradient descent optimization.

Parameters:learning_rate=0.05, n_estimators=150
Target:Attrition Rate (Continuous)
Model 3: Linear Regression

Standard parametric baseline architecture used to quantify structural non-linear dataset complexities.

Parameters:fit_intercept=True, copy_X=True
Target:Attrition Rate (Continuous)
