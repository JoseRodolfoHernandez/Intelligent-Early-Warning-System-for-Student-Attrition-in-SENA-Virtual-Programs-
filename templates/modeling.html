Phase 4: Model Engineering

Model Selection & Architecture

For the student retention framework, we implemented an Ensemble Learning Model (Random Forest / Gradient Boosting) using scikit-learn. Ensemble methods are highly effective at mapping non-linear relations between high-cardinality demographic distributions (like regionals) and systemic classroom dropouts.

Training Hyperparameters

  • Estimators: 100 decision tree structures running parallel matrix processing layers.
  • Max Depth: Capped to prevent overfitting anomalies over short complementary courses.
  • Serialization: The model pipeline is compiled directly into binary arrays via joblib utilities as attrition_model.pkl.
