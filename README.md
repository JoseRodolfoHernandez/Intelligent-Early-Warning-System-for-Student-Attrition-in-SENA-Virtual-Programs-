# Intelligent Early Warning System for Student Attrition - SENA

## 🚀 Project Overview
This project aims to predict student attrition in virtual training programs at SENA using Machine Learning. Following the **CRISP-ML** methodology, we identify high-risk courses to enable early pedagogical interventions.

## 🛠️ Methodology: CRISP-ML
1. **Business Understanding:** Aligning academic goals with data from `datos.gov.co`.
2. **Data Engineering:** Filtering virtual modality and feature extraction (Course Duration).
3. **Model Engineering:** Random Forest Regressor for attrition forecasting.
4. **Deployment:** Web application hosted on **Render**.

## 📂 Project Structure
- `data/`: Processed datasets.
- `src/`: Python scripts (Preprocess, Train, App).
- `requirements.txt`: Project dependencies.

## 💻 Tech Stack
- **Python:** Pandas, Scikit-Learn, Streamlit.
- **Deployment:** Render.
